# Inventario para PyME

Aplicación web para gestionar el inventario de una PyME de insumos informáticos y reparaciones.

## Objetivo

Mejorar la confiabilidad del stock, registrar movimientos y facilitar las decisiones de reposición.

## Funcionalidades principales

- Gestión de productos.
- Stock por local y depósito.
- Entradas, salidas, transferencias y ajustes.
- Historial y trazabilidad.
- Punto de reposición.
- Alertas de stock bajo.
- Reporte de rotación.
- Usuarios y roles.

## Tecnologías

- Frontend:       Angular + TypeScript
- Backend:        NestJS + TypeScript
- API:            REST
- Base de datos:  PostgreSQL
- ORM:            Prisma
- Testing:        Jest + Supertest
- Documentación:  Swagger / OpenAPI
- Repositorio:    Monorepo
- CI:             GitHub Actions

## Estructura

- `/frontend`: aplicación web.
- `/backend`: API y lógica de negocio.
- `/docs`: documentación y decisiones del proyecto.
